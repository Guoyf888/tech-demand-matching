## 一、项目概述

### 1.1 项目目标
构建一个面向技术经理人的技术需求智能对接平台，实现企业（需求方）、高校/科研院所（技术方）、服务机构（平台方）三方之间的技术需求高效对接。

### 1.2 核心价值
- **需求方**：输入技术需求，获得AI自动分析、标签分类、企业画像、技术研发路线图和创新建议
- **技术方**：上传技术成果，AI自动提炼通俗易懂的成果展示，清晰呈现团队实力
- **平台方**：撮合合作，智能匹配需求方与技术方，管理合作项目

### 1.3 技术选型
| 类别 | 选择 |
|------|------|
| **部署形式** | 桌面APP（Windows/Mac） - Tauri打包 |
| 架构模式 | React前端 + Rust后端（Tauri） |
| 数据存储 | 本地文件系统 + IndexedDB |
| 前端框架 | React + TypeScript + Vite |
| AI能力 | 各大模型厂商API |
| UI风格 | 现代简洁（参考WiseMindAI） |

## 三、功能模块设计

### 3.1 需求方（企业端）功能

| 功能 | 描述 |
|------|------|
| 技术需求输入 | 文本框输入技术需求或技术方向 |
| AI自动打标签 | 基于层级标签树自动分类打标 |
| 企业信息分析 | AI联网搜索企业公开信息 |
| 行业分析报告 | 分析对应技术行业发展动态 |
| 技术研发路线 | 生成研发路线图和技术创新建议 |

**标签体系：** AI自动分类 + 层级标签树
- 示例：人工智能 → 机器学习 → 深度学习 → NLP

### 3.2 技术方（高校/院所端）功能

| 功能 | 描述 |
|------|------|
| 技术成果上传 | 上传技术成果文档/资料 |
| AI自动打标签 | 成果自动分类打标 |
| 成果概要提炼 | AI将成果提炼为通俗易懂的概要 |
| 团队卡片展示 | 展示团队成员和实力（卡片式） |
| 成果管理 | 技术成果的增删改查 |

### 3.3 平台方（服务机构端）功能

| 功能 | 描述 |
|------|------|
| 需求广场 | 查看所有待匹配的技术需求 |
| 技术广场 | 查看所有待匹配的技术成果 |
| 智能匹配 | 大模型驱动需求方与技术方匹配 |
| 合作管理 | 管理促成合作的项目 |
| 匹配报告 | 生成匹配分析报告 |

### 3.4 系统层功能

| 功能 | 描述 |
|------|------|
| 大模型配置 | API Key配置、多模型切换 |
| Token配额管理 | 余额查询、用量统计、费用预警 |
| 自定义模型 | 支持私有模型和OpenAI兼容接口 |

## 五、数据存储

### 5.1 存储方式
- **本地文件系统**：通过 Tauri Rust 后端访问，存储结构化数据
- **SQLite + FTS5**：本地全文搜索数据库（借鉴Hermes Agent）
- **IndexedDB**：浏览器端大容量数据缓存

### 5.2 数据分类
- 用户配置信息（API Key、偏好设置）
- 技术需求数据（需求文档、分析报告）
- 技术成果数据（成果文档、团队信息）
- 匹配记录和历史
- Skill技能数据
- 记忆/知识图谱数据

### 5.3 桌面特性
- **系统托盘**：后台运行、快捷入口
- **原生对话框**：文件选择、目录选择
- **离线优先**：无网络也能访问本地数据

## 七、Skill 技能系统（借鉴 Hermes Agent）

### 7.1 设计目标
借鉴 Hermes Agent 的技能系统，构建**自主进化**的技能生态

### 7.2 核心特性

| 特性 | 描述 |
|------|------|
| **技能自动创建** | 从复杂任务中自动提炼创建新技能 |
| **技能自优化** | 技能在使用中持续学习和改进 |
| **技能市场** | 浏览、安装社区共享的技能 |
| **技能学习** | 技能可从成功案例中积累经验 |
| **技能版本管理** | 支持技能的历史版本和回滚 |

### 7.3 技能结构
```
Skill = {
  id: string,
  name: string,
  description: string,
  version: string,
  actions: Action[],
  prompts: Prompt[],
  tools: Tool[],
  learnings: Learning[],  // 从使用中积累的经验
  metadata: {
    createdAt: Date,
    usageCount: number,
    successRate: number
  }
}
```

### 7.4 内置工具集（40+）
借鉴 Hermes Agent 内置工具：
- 搜索工具（网络搜索、文档搜索、历史搜索）
- 文档处理（PDF解析、Word解析、Markdown转换）
- 代码处理（代码审查、代码生成、代码解释）
- 数据分析（数据分析、可视化、报告生成）
- 通信工具（邮件发送、消息推送、API调用）
- 文件管理（文件读写、压缩解压、格式转换）

### 7.5 记忆持久化
- **会话记忆**：自动保存当前会话关键信息
- **跨会话记忆**：用户画像、技术偏好、合作历史
- **知识图谱**：自动构建技术领域知识图谱
- **FTS5 全文搜索**：毫秒级检索历史需求、成果、对话
