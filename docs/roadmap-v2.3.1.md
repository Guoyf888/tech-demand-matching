# v2.3.1 配置与功能审查及后续路线图

审查日期：2026-09-05

## 当前基线

- 产品闭环：需求管理 → 成果管理 → 专业匹配 → 人工复核 → 对接项目推进。
- 桌面技术栈：Tauri 2、React 18、TypeScript、Vite 7、Zustand、Tailwind CSS 3。
- AI 配置：12 个 Provider 由 `src/config/providers.ts` 单点维护。
- 数据模式：业务数据主要保存在 localStorage，API Key 优先存入系统 Keychain。
- 验证基线：20 个测试文件、78 项测试通过；Windows x64 MSVC/NSIS 构建与启动通过。

## 建议优先级

### P0：建议进入 v2.3.2 的稳定性与安全修复

1. **收紧桌面 Shell 权限**
   - 当前主窗口声明 execute、spawn、stdin-write 和 kill 权限。
   - 先盘点终端页实际命令，再按必要命令和参数建立白名单，避免给全部业务页面相同权限。

2. **消除 Keychain 静默降级**
   - 桌面端 Keychain 写入失败时会自动降级到 localStorage + XOR 混淆。
   - 设置页应显示“系统安全存储 / 本地兼容存储”状态；正式发布模式下建议由用户明确确认后才允许降级。

3. **补齐备份冲突与数据迁移策略**
   - 当前备份 schema 为 1；数组合并遇到相同 id 时保留本机旧记录，可能忽略备份中的较新项目进展。
   - 建议按 updatedAt 解决冲突、生成导入预览，并为 match_projects 建立显式迁移版本。

4. **修复发布配置警告**
   - Tauri 标识 `com.techdemand.app` 以 `.app` 结尾，构建持续产生跨平台标识警告。
   - 修改标识会影响已安装应用身份，需在正式分发前一次性确定，并验证旧测试版卸载/升级路径。

### P1：建议作为 v2.4.0 的专业工作台 UI 2.0

1. **项目视图升级**
   - 增加“看板 / 表格”视图切换；表格适合批量筛选，看板适合阶段推进。
   - 卡片只保留摘要，编辑内容进入右侧详情抽屉，降低长列表滚动成本。

2. **统一任务与活动时间线**
   - 每次阶段、负责人、截止日和备注变更形成不可覆盖的活动记录。
   - 将“下一步行动”升级为可完成的待办，支持负责人、截止日和完成状态。

3. **重构工作台导航层级**
   - 侧边栏“专业匹配”下增加“匹配评估 / 项目推进”二级入口，并展示逾期数量。
   - 保留页内切换，但让用户可直接进入待处理项目，不必先进入匹配评估。

4. **桌面信息密度与响应式基线**
   - 对 1280×800 和最小 1024×600 建立固定视觉回归用例。
   - 统计区在低高度窗口改为紧凑横条；筛选区保持吸顶；表单标签、风险色和按钮状态统一为设计令牌。

5. **统一反馈组件**
   - 技能导入、草稿保存、设置重置和成果建议仍使用浏览器 alert。
   - 统一替换为 Toast、确认对话框和页面内错误提示，避免打断桌面工作流。

6. **无障碍与键盘效率**
   - 页签补充方向键切换和 roving tabindex；筛选控件补充明确标签。
   - 为常用操作增加快捷键和清晰焦点样式，并纳入自动化可访问性检查。

### P1：性能与工程质量

1. **科学技能延迟加载**
   - 当前 `scientificSkills.ts` 使用 eager glob，把全部 SKILL.md 内容打入约 2.27 MB 的单一资源块。
   - 首屏只加载技能元数据，命中推荐后再加载正文，可显著降低启动解析与内存开销。

2. **补充端到端测试**
   - 当前 131 个 src 文件中有 20 个测试文件，业务服务覆盖较好，但页面流程覆盖不足。
   - 优先覆盖“匹配 → 认可 → 建档 → 修改阶段 → 备份恢复”和 1024×600 桌面窗口。

3. **受控依赖升级**
   - 当前锁定依赖存在可用的小版本更新，Tauri API/CLI/Plugin Shell 可单独建立兼容升级批次。
   - React 19、Vite 8、Tailwind 4、Zustand 5 等大版本应分支迁移，不与业务版本混合升级。

### P2：产品价值增强

1. 增加企业/成果方联系人、参与角色和关键干系人视图。
2. 增加验证材料、会议纪要、知识产权核验和商务文件附件索引。
3. 增加漏斗指标：匹配数、认可率、建档率、验证通过率、签约率和平均推进周期。
4. 增加项目关闭原因和失败复盘，为后续匹配权重优化提供真实反馈数据。

## 推荐版本顺序

- **v2.3.2**：Shell 权限、Keychain 降级提示、备份冲突和发布配置审查。
- **v2.4.0**：专业工作台 UI 2.0、项目活动时间线和可执行待办。
- **v2.4.1**：科学技能延迟加载、端到端测试和性能回归。
- **v2.5.0**：转化漏斗、复盘数据和匹配反馈学习。
